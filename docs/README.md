# Документация Race to the Bottom

Актуализировано 28 октября 2026. Все инструкции проекта находятся в этой папке.

| Документ | Когда читать |
| --- | --- |
| [DEPLOYMENT.md](DEPLOYMENT.md) | Локальный запуск, текущая инфраструктура, автоматическая публикация, настройки GitHub и восстановление |
| [ANDROID_TV.md](ANDROID_TV.md) | Сборка, подпись, установка и диагностика APK для телевизора |
| [GAME_RULES.md](GAME_RULES.md) | Подключение игроков и действующие правила игры |
| [APP_MAP.md](APP_MAP.md) | Где искать код, как проходит ход и что сохраняет устройство |
| [SUPABASE_SETUP.md](SUPABASE_SETUP.md) | Таблицы, права, серверные функции и создание нового backend |
| [IMPROVEMENTS.md](IMPROVEMENTS.md) | Единый список задач, приоритетов и предложений по интерфейсу |
| [BOARD_REDESIGN.md](BOARD_REDESIGN.md) | Согласованный проект постоянной доски и перехода на новую модель данных |
| [ARCHITECTURE_OPTIONS.md](ARCHITECTURE_OPTIONS.md) | Обсуждаемые варианты смены инфраструктуры; не инструкция текущего деплоя |

Основной сайт: [race-to-the-bottom.vercel.app](https://race-to-the-bottom.vercel.app/).
Обычное обновление: изменения → проверки → merge в `main` → GitHub Actions выпускает Supabase → Vercel публикует сайт после успешных проверок. Подробности и ручной способ — в [DEPLOYMENT.md](DEPLOYMENT.md). Для обычного обновления игры новый APK обычно не нужен.

Прежние `CI_CD_SETUP.md` и `DEPLOYMENT.md` объединены в одну инструкцию деплоя; Android-инструкции собраны в `ANDROID_TV.md`. Пункты `todo.md` включены в `IMPROVEMENTS.md`. Спецификация первого офлайн-прототипа убрана как устаревшая: действующие правила и устройство приложения описаны отдельно. Предыдущие версии документов доступны в истории Git.

Команды во всех руководствах выполняются из корня репозитория, если прямо не указано другое. Пути к исходникам вида `src/...` также отсчитываются от корня.
