# Инструкции проекта

Для задач по коду используй skill `ponytail` в режиме `full` по умолчанию, если пользователь не выбрал другой режим или не отключил его. Сначала изучи затронутый код, по возможности используй существующий код проекта и возможности платформы и вноси минимальное полное изменение. Сохраняй необходимую проверку данных, обработку ошибок, безопасность, доступность и тесты. Если skill недоступен, следуй этим принципам и сообщи пользователю, что skill не удалось загрузить.
