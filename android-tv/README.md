# Race to the Bottom — Android TV

Приложение `com.racetothebottom.tv`, версия 1.6 (7), Android 6+. Установлено на TCL Android TV 11.

Приложение открывает https://race-to-the-bottom-36n.pages.dev/?screen=tv через WebView. Интерфейс не включён в APK: для дальнейших изменений достаточно публиковать новую сборку сайта и перезапускать приложение либо выбирать «Обновить доску» в меню пульта. Интернет необходим и для загрузки сайта, и для игрового сервера Supabase. При сетевой ошибке доступен повтор подключения. После перехода с bundled-версии 1.5 меняется origin хранилища WebView, поэтому первоначально создаётся новая доска.

ТВ автоматически создаёт или восстанавливает лобби. Первый игрок становится лидером, телефоны подключаются по коду или QR-ссылке. Имя игрока сохраняется на его устройстве в cookie на год с SameSite=Lax (Secure на HTTPS); localStorage используется как совместимый запасной вариант. Ссылка содержит только код комнаты. При смене лобби QR обновляется.

ТВ-оформление рассчитано в том числе на 960×540 логических пикселей: компактная шапка, рынок и таблица на одном экране, готовность рядом с именами. Раскрытие помещает до пяти карт в один ряд.

WebView разрешает навигацию только на HTTPS-домен сайта, не имеет JavaScript-моста к Android и доступа к локальным файлам. «Назад»/Menu открывает обновление доски и выход. Экран остаётся включённым, ориентация альбомная. Ключи управления не встроены в APK.

## Сборка и установка

Для изменений только сайта APK собирать не нужно. Для изменений Android-оболочки нужны JDK 17, Android SDK Platform 35 и Build Tools 35. Указать TV_JAVA_HOME, TV_BUILD_TOOLS, TV_ANDROID_JAR, TV_SIGNING_DIR, опционально TV_APK_OUTPUT, затем выполнить `python3 scripts/build.py`.

Каталог `.signing` содержит постоянный ключ подписи и пароль, исключён из Git. Его нужно сохранить локально для обновлений APK; не публиковать и не включать в архив сайта. `build/` содержит промежуточные файлы, также исключён из Git. APK собирается без веб-ресурсов.

После разрешённого пользователем ADB-подключения: `adb -s <IP>:5555 install --no-incremental -r race-to-the-bottom-tv.apk`. Приложение доступно в меню Android TV.

В `connection-check.txt` в каталоге внешних файлов приложения сохраняются краткие этапы загрузки и HTTP-статусы без ключей и тел запросов/ответов. Размер ограничен 64 КиБ. Игровые запросы ограничены по времени; open-display возвращает хаб и комнату одним ответом.
